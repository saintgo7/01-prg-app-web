## 🎯 개요

이 저장소는 **1,980개**의 프로덕션 준비 완료 프로그램 템플릿을 포함합니다. 각 템플릿은 다음을 제공합니다:

- ✅ **즉시 실행 가능한 설정**
- ✅ **상세한 한국어 문서** (README.md)
- ✅ **프레임워크별 최적화된 .gitignore**
- ✅ **환경 변수 예시** (.env.example)
- ✅ **Best Practice 적용**

## 🚀 빠른 시작

### 1. 저장소 클론

```bash
git clone <repository-url>
cd 01-prg-app-web
```

### 2. 원하는 템플릿 선택

```bash
# 예: Next.js 템플릿
cd 001_web_nextjs

# 또는 Jest 테스팅 템플릿
cd 1551_testing_jest
```

### 3. 의존성 설치

```bash
npm install
# 또는
yarn install
# 또는
pnpm install
```

### 4. 환경 변수 설정

```bash
cp .env.example .env
# .env 파일을 편집하여 필요한 환경 변수 설정
```

### 5. 개발 서버 실행

```bash
npm run dev
# 또는
yarn dev
```

## 🛠️ 개발 도구

이 저장소에는 다음 유틸리티 스크립트가 포함되어 있습니다:

- `generate_templates.py` - 초기 템플릿 생성
- `add_programs.py` - 추가 프로그램 템플릿 생성
- `complete_templates.py` - 템플릿 컬렉션 완성
- `improve_templates.py` - 템플릿을 프로덕션 준비 상태로 변환
- `improve_all_templates.py` - 모든 템플릿에 한국어 문서 추가
- `add_200_new_templates.py` - 200개 새 템플릿 추가 (1551-1750)
- `add_200_more_templates.py` - 230개 추가 템플릿 (1751-1980)
- `improve_popular_templates.py` - 인기 템플릿에 실제 코드 추가
