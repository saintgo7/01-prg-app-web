# Neo4j

## 카테고리
DATABASE

## 설명
Neo4j 데이터베이스를 사용한 프로젝트 템플릿

## 번호
1428

## 시작하기

### 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

### 프로덕션 빌드
```bash
npm run build
```

## 기능
- Neo4j 기반 프로젝트
- 모던 개발 환경 설정
- 기본 템플릿 제공

## 기술 스택
- Neo4j
- Node.js
- npm/yarn
