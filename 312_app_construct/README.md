# Construct

## 카테고리
APP

## 설명
Construct 모바일/데스크톱 앱 프레임워크를 사용한 프로젝트 템플릿

## 번호
312

## 시작하기

### 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

### 프로덕션 빌드
```bash
npm run build
```

## 기능
- Construct 기반 프로젝트
- 모던 개발 환경 설정
- 기본 템플릿 제공

## 기술 스택
- Construct
- Node.js
- npm/yarn
