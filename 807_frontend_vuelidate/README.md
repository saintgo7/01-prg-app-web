# Vuelidate

## 카테고리
FRONTEND

## 설명
Vuelidate 프론트엔드 라이브러리/도구를 사용한 프로젝트 템플릿

## 번호
807

## 시작하기

### 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

### 프로덕션 빌드
```bash
npm run build
```

## 기능
- Vuelidate 기반 프로젝트
- 모던 개발 환경 설정
- 기본 템플릿 제공

## 기술 스택
- Vuelidate
- Node.js
- npm/yarn
