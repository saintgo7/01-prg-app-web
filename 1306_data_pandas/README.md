# Pandas

## 카테고리
DATA

## 설명
Pandas 데이터 처리/분석 도구를 사용한 프로젝트 템플릿

## 번호
1306

## 시작하기

### 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

### 프로덕션 빌드
```bash
npm run build
```

## 기능
- Pandas 기반 프로젝트
- 모던 개발 환경 설정
- 기본 템플릿 제공
