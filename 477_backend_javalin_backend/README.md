# Javalin Backend

## 카테고리
BACKEND

## 설명
Javalin Backend 백엔드 프레임워크/도구를 사용한 프로젝트 템플릿

## 번호
477

## 시작하기

### 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

### 프로덕션 빌드
```bash
npm run build
```

## 기능
- Javalin Backend 기반 프로젝트
- 모던 개발 환경 설정
- 기본 템플릿 제공

## 기술 스택
- Javalin Backend
- Node.js
- npm/yarn
